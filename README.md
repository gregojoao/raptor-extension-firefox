# 🦖 Raptor Extension para Firefox

Conecte sua Amazon no Raptor em poucos minutos. A extensão só copia o seu login da página aberta — ela **não pede nem guarda senha**.

## 👉 [Clique aqui para instalar](https://gregojoao.github.io/raptor-extension-firefox/)

> Abra o link **no Firefox**. Ainda não tem? Baixe grátis em [firefox.com](https://www.firefox.com/pt-BR/).

---

## 1) Instalar (uma vez só)

1. Abra **[a página de instalação](https://gregojoao.github.io/raptor-extension-firefox/)** no Firefox e clique no botão laranja **Instalar no Firefox**.
2. O Firefox pergunta se o site pode instalar um complemento → **Permitir**.
3. Aparece *"Adicionar Raptor Extension?"* → **Adicionar**.
4. Na confirmação, **marque "Permitir que esta extensão seja executada em janelas privativas"** → **OK**.
5. Libere o acesso aos sites: digite `about:addons` na barra de endereço → **Raptor Extension** → aba **Permissões** → ligue todas as chavinhas.
6. *(Opcional)* Ícone de quebra-cabeça 🧩 no canto superior direito → engrenagem da Raptor Extension → **Fixar na barra de ferramentas**.

## 2) Conectar a Amazon

1. Abra uma **janela privativa**: `Ctrl` + `Shift` + `P` (no Mac: `⌘` + `Shift` + `P`).
2. Entre em **associados.amazon.com.br** e faça login. Se aparecer, marque **"Manter-me conectado"**.
3. Com a página aberta, clique no ícone **⚡ RAPTOR**.
4. Clique em **Copiar**.
5. No painel do Raptor → **Integrações** → **Amazon** → cole e **salve**.
6. **Feche a janela privativa** no X — **sem clicar em "Sair"** na Amazon.

✅ Pronto!

## ⚠️ Importante

- **Use o Firefox, não o Chrome.** No Chrome, a Amazon derruba esse login em poucos minutos.
- **Nunca clique em "Sair"** na Amazon depois de salvar.
- Use a **janela privativa** e feche depois — assim o Raptor é o único usando esse login e ele dura muito mais.
- Se o Raptor avisar que a Amazon desconectou, repita a parte **2) Conectar a Amazon**.

## Dúvidas comuns

**Cliquei e só baixou um arquivo.** Você está em outro navegador. Abra o link no Firefox.

**A extensão diz "Vazio".** Confira se está logado na Amazon Associados *nessa mesma janela* e se ligou as permissões (passo 5). Depois clique em **Recapturar**.

**O ícone não aparece na janela privativa.** Falta permitir em janelas privativas (passo 4).
